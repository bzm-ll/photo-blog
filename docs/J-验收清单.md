## 二、双语

| ✓ | 检查 | 怎么验 |
| --- | --- | --- |
| ☐ | 中文站不带前缀 | `/` 能打开 |
| ☐ | 英文站带 `/en` | `/en/` 能打开且内容变英文 |
| ☐ | 语言切换是镜像 | 在 `/works/fog-harbour/` 点 EN → `/en/works/fog-harbour/`（不是回首页） |
| ☐ | 缺英文时回退中文 | 某条只填了中文 → 英文站显示中文，不空白 |
| ☐ | `hreflang` 三向声明 | 查看源代码，有 zh-CN / en / x-default 三条 |
| ☐ | `<html lang>` 正确 | 中文页 `lang="zh-CN"`，英文页 `lang="en-US"` |

## 三、SEO

| ✓ | 检查 | 怎么验 |
| --- | --- | --- |
| ☐ | 每页有 title | 浏览器标签页显示「雾港 — [博客名]」 |
| ☐ | 每页有 description | 查看源代码 `<meta name="description">` 非空 |
| ☐ | canonical 是绝对网址 | 应为 `https://你的名字.netlify.app/works/fog-harbour/` |
| ☐ | OG 分享卡片 | 把网址发到微信/Telegram，有标题+图 |
| ☐ | JSON-LD 结构化数据 | 源代码里有 `"@type":"Article"`、`"BreadcrumbList"`、`"Person"` |
| ☐ | sitemap | `/sitemap-index.xml` 能打开 |
| ☐ | robots.txt | `/robots.txt` 里 Sitemap 指向你真实域名 |
| ☐ | 404 不被索引 | 404 页有 `noindex` |
| ☐ | 已提交给 Google | https://search.google.com/search-console 添加站点并提交 sitemap（可选但强烈建议） |

✅ 已在构建产物中验证：canonical / hreflang / og:image 绝对地址 / Article+BreadcrumbList+ImageObject+Person JSON-LD 均正确输出。
